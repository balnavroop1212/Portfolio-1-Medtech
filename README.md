# AETHER-01 — Optical Technology & Engineering

A luxury, interactive 3D scroll-driven showcase for the **AETHER-01** optical technology device. Built with React, TypeScript, Tailwind CSS, Lucide icons, and modern HTML5 canvas frame streaming.

## 🌟 Highlights

- **Cinematic 3D Scroll Sequence**: High-density 60fps optical chassis animation synchronized with page scroll depth.
- **Smoked Obsidian Glass Cards**: Frosted obsidian backdrop-filtered cards with subtle borders and lighting effects.
- **Capsule Navigation System**: Floating pill navbar with active section scroll-spy and protected frosted logo pill.
- **Zero-Overlap Architecture**: Generous section spacing and docked card rails that keep the central optical hardware 100% visible.
- **Interactive Audio Feedback**: Subtle tactile sound design on navigation clicks and form actions.
- **Responsive Layout**: Designed for high-resolution desktop displays down to mobile touchscreens.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS / Tailwind CSS, React 19, TypeScript
- **Icons**: Lucide React
- **Dev Server / Bundling**: Vite, Node.js static server (`server.js`)
- **Animation**: Canvas 2D frame stream preloading & requestAnimationFrame interpolation

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/balnavroop1212/Portfolio-1-Medtech.git

# Navigate into the project directory
cd Portfolio-1-Medtech

# Install dependencies
npm install
```

### Running Locally

```bash
# Start with Node static server (port 3000)
node server.js

# Or start with Vite dev server
npm run dev
```

Visit `http://localhost:3000` in your browser.
